# Character model

Drop your 3D character file here, e.g. `character.glb`.

- Format: glTF 2.0, as a single `.glb` file (mesh + textures + animations
  bundled together). If your export tool only produces `.gltf` + loose
  texture files, upload the whole folder so relative paths stay intact.
- Animations should have clear names (`Idle`, `Walk`, etc.) if possible.
- Let us know whether the model can rotate/turn, or only faces one
  direction — that changes how movement gets hooked up.
